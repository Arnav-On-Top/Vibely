An Music Player where user can upload music as an mp3 file. Playlist can be rearranged and repeat can be set to 1 2 3 or infinity. Also contains volume control and basic audio buttons like play, next and previous buttons.

To run it, click this link https://arnav-on-top.github.io/Vibely/ or click the link in the deployment.

Built as a project for Hack Club's GrandMa YSWS [You Ship We Ship] Program under the constrains of:

1. No server or database: all state lives in the URL or the browser.

2. No image files: CSS, SVG, canvas or text only.

3. No if statements, switches or ternaries.
